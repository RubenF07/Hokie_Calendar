# Hokie_Calendar
Welcome to Hokie Calendar! This application allows Virginia tech students to add, edit, and remove customized events in a personal calendar format. However, to add a Hokie twist, specialized Hokie events including football games and breaks are built into the calendar.


This code is written in Java. The classes are Main, Display, Calendar, Month, Day, Event, TimedEvent, and Time classes. All classes are located in the calendar package. TimedEvent is a subclass of Event. TestClasses include key methods in Month, Day, and Time classes.


Instructions for use:
1. Open the project file in Eclipse 
2. Navigate to the Main Class
3. Run the program from the Main Class
4. Interact with the console to use Hokie Calendar
5. Use the menu options to navigate and manage your calendar
