# Hokie_Calendar
Welcome to Hokie Calendar! This application allows Virginia tech students to add, edit, and remove customized events in a personal calendar format. However, to add a Hokie twist, specialized Hokie events including football games and breaks are built into the calendar.


This code is written in Java. The classes are Main, Display, Calendar, Month, Day, Event, TimedEvent, and Time classes. All classes are located in the calendar package. TimedEvent is a subclass of Event. TestClasses include key methods in Month and Day classes.


To use this application, navigate to the Main class. From there, run the code!
To use the calendar, follow the detailed instructions in the console.
